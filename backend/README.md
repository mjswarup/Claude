# CareerForge AI Backend

This backend service is built with Node.js, Express, and TypeScript. It exposes the core REST APIs for user authentication, resume management, and AI orchestration.

## Key features
- Express API server with security middleware
- Structured routes for auth and resume workflows
- Environment-based configuration by `.env`
- Placeholder endpoints for rapid MVP development

## Run locally
1. Install dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Start the server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:4000/api/health

## Build
```bash
cd backend
npm run build
```
