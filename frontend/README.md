# CareerForge AI Frontend

This frontend is built with React, Vite, and TypeScript. It provides the user-facing interface for the CareerForge AI SaaS platform, including onboarding, dashboard, and AI assistant workflows.

## Key features
- Fully typed React application
- Client-side routing with `react-router-dom`
- API service layer for backend integration
- Simple responsive layout and component design

## Run locally
1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:4173

## Production build
```bash
cd frontend
npm run build
```
